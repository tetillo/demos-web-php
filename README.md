# demos-web-php

Prototipos de páginas web en PHP 8, HTML, CSS y algo de JavaScript, hechos como práctica y portfolio para negocios locales de Pinto y Las Tablas (Madrid).

**Importante**

- No son encargos ni sitios oficiales. Los negocios no han participado ni han dado permiso.
- Los textos, productos, precios y horarios son de ejemplo o ficticios. Las direcciones y enlaces a Google Maps son públicos; los teléfonos y correos se han sustituido por valores de ejemplo.
- Los formularios validan los campos con PHP, pero no envían correos, no guardan datos y no hacen reservas ni pedidos.
- Las ilustraciones son propias (SVG). No se incluyen fotos de terceros.
- Antes de usar cualquiera con un negocio real hacen falta su permiso, datos actualizados, textos legales y un sistema de envío real.

## Cómo ejecutarlo

Necesitas PHP 8 o superior (o XAMPP). Dentro de la carpeta de una demo:

```
php -S localhost:8000
```

y abre http://localhost:8000. Cada carpeta tiene también un `preview.html` estático para verla sin instalar nada, y su propio README con detalles.
